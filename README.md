## Purpose

This repository defines a Proof Protocol mapping between the ORCHIDEAS framework and Proof Protocol evidence, efficacy, and proof semantics.

The mapping treats ORCHIDEAS as a source of threat, behavior, and test context. Proof Protocol remains independent of the source framework and produces its own evidence and proof artifacts.

## Upstream source

ORCHIDEAS materials are referenced for interoperability and mapping purposes. No upstream ownership is asserted by this repository.

## Architectural principle

> **Threat frameworks are pluggable inputs to Proof Protocol. Proof Protocol is framework-agnostic.**

External frameworks describe what may be tested. Proof Protocol independently establishes whether a control worked and what evidence proves the result.
